# Instrucciones para agentes de IA

1. Antes de hacer cualquier cosa, leé **`PROYECTO_STOCKDEPO.md`** (documento maestro: contexto, decisiones, fases y estado).
2. Respondé al usuario siempre en **español**.
3. Todo debe ser **gratuito y local** (sin nube, salvo la API gratuita de Gemini ya acordada).
4. El diseño de referencia es `docs/mockup_v0.2.html`.
5. Al completar una tarea: tildala en `PROYECTO_STOCKDEPO.md` y agregá una línea en "Registro de avances".
6. Nunca guardes claves (Gemini, Gmail) en el código ni en estos documentos.
